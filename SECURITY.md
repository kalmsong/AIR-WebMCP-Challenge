# Security

This repository contains a public reference implementation of AIR's WebMCP interaction pattern.

It intentionally contains no production credentials, API keys, account data, billing configuration, database connection strings, or private AIR provider integrations.

Please do not commit secrets or test-account credentials to this repository. Keep judge-only credentials in the hackathon submission form or another private channel.

If you discover a security issue in the public reference, report it privately to the repository owner rather than opening an issue that contains sensitive details.
